Title: Method for extracting IP information in transient electromagnetic response of a grounding wire source
Abstract: The invention discloses a method for extracting IP information in a transient electromagnetic response of a grounding wire source. The method comprises the following steps of (1) obtaining undergroundresistivity information by inversion of a vertical magnetic field which is less influenced by an IP effect, (2) obtaining an electric field response which is not influenced by the IP effect based onobtained underground electrical structure forward modeling, (3) removing the influence of the IP effect in an observed response to obtain a pure IP response, and (4) carrying out inversion on the obtained IP response to obtain IP information of polarizability, a frequency correlation coefficient and a time constant. The method provides a new thought for further extracting the IP information from the transient electromagnetic response.

Title: Computer architecture for identifying data clusters using correlithm objects and machine learning in a correlithm object processing system
Abstract: A device that includes a model training engine implemented by a processor. The model training engine is configured to obtain a set of data values associated with a feature vector. The model training engine is further configured to transform a first data value and a second data value from the set of data value into sub-string correlithm objects. The model training engine is further configured to compute a Hamming distance between the first sub-string correlithm object and the second sub-string correlithm object and to identify a boundary in response to determining that the Hamming distance exceeds a bit difference threshold value. Title: Quantum calculation-based minimum mean square error detection method
Abstract: The invention discloses a hybrid large-scale MIMO arrival direction estimation method based on quantum computing. The method comprises the following steps: S1, constructing a spatial covariance matrix in a quantum state form according to quantum singular value estimation; S2, implementing a density matrix eigendecomposition algorithm according to a variational principle, and performing eigendecomposition on the covariance matrix in the step S1 to obtain eigenvectors; S3, realizing quantum marking operation according to the special positive vector obtained in the step S2, and realizing direction-of-arrival search. According to a traditional arrival direction estimation algorithm in a hybrid large-scale MIMO communication system, a quantum singular value estimation algorithm, a quantum available data structure and a variable component sub-algorithm are adopted, the complexity of the traditional arrival direction estimation problem is reduced, and therefore more stable performance is obtained.
